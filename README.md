# Знайди репетитора

Адаптивний вебсайт платформи для пошуку індивідуальних репетиторів з університетських дисциплін.

## Живий сайт
[Переглянути проєкт на GitHub Pages](https://serg2098.github.io/find-tutor/)

## Реалізований функціонал
- Семантична HTML5-розмітка та адаптивна верстка на Flexbox і CSS Grid (desktop, tablet, mobile).
- Мобільне бургер-меню без JavaScript.
- Оптимізовані зображення, фонові медіасекції з відео та зображенням.
- Інтерактивна форма заявки для викладачів із валідацією та адаптивна таблиця ставок.
- Картки тарифних пакетів та репетиторів.
- Плавні CSS-переходи (`transition`), перетворення (`transform`), каскадна поява першого екрана (`@keyframes`) та підтримка `prefers-reduced-motion`.

## Технології
- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Media Queries, Animations)
- Git / GitHub Pages
